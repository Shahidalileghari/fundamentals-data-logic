# Software Engineering Fundamentals — Logic, Programming & Data

A practical foundation course covering computational thinking, logic, programming, data representation, algorithms, data structures, complexity, debugging, testing, and software design. Examples use Python 3.11+ for readability; concepts transfer to Java, C++, JavaScript, Dart, and other languages.

## Outcomes
- Translate requirements into inputs, outputs, constraints, and edge cases.
- Design algorithms with decomposition, abstraction, pseudocode, and invariants.
- Understand types, control flow, functions, recursion, memory, references, and binary data.
- Select arrays, maps, sets, stacks, queues, trees, heaps, and graphs appropriately.
- Analyze time/space complexity and implement core algorithms.
- Debug systematically, test behavior, and design modular programs.

## Run
```bash
python --version
python examples/hello_logic.py
python -m unittest discover -s tests -v
```
No third-party dependencies are required.

## Structure
- `curriculum/` — 20 progressive lessons.
- `examples/` — runnable Python demonstrations.
- `exercises/` and `solutions/` — practice and selected answers.
- `projects/` — three practical projects.
- `tests/` — standard-library automated tests.
- `cheatsheets/` and `docs/` — reference material and assessment.

## Learning sequence
1. Logic and computational thinking.
2. Programming and data representation.
3. Algorithms and data structures.
4. Debugging, testing, and software design.
5. Complete projects and explain design trade-offs.
