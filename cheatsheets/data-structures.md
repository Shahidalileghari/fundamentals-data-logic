# Data structure selection

| Structure | Use | Typical operation |
|---|---|---|
| Dynamic array | Indexed sequence | index O(1), append amortized O(1) |
| Linked list | Local insertion | search O(n) |
| Stack | Undo/parsing | push/pop O(1) |
| Queue | Scheduling/BFS | enqueue/dequeue O(1) |
| Hash map | Key lookup | average O(1) |
| Balanced BST | Ordered data | O(log n) |
| Heap | Priority queue | insert/remove O(log n) |
| Graph | Relationships | BFS/DFS O(V+E) |
