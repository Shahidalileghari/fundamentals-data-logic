# Glossary

Algorithm: finite procedure. Abstraction: retain relevant details. Invariant: property maintained. Type: classification of values/operations. Reference: access to an object. Aliasing: multiple references to one object. Recursion: self-calls on smaller problems. Data structure: organization of data. Big-O: asymptotic growth. Cohesion: relatedness of module responsibilities. Coupling: interdependence. Regression test: guards against a fixed defect.
