# 11 — Complexity

Big-O describes asymptotic resource growth. Common classes: O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ). Analyze dominant growth and state assumptions. Distinguish auxiliary space from input storage. Hash table O(1) lookup is average-case, not a universal worst-case guarantee. Analyze linear/binary search and merge sort.
