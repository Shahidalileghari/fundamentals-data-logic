# Data and algorithm exercises

1. Convert decimal to binary without a built-in helper.
2. Count vowels, consonants, digits, and spaces.
3. Remove duplicates preserving order.
4. Merge sorted arrays.
5. Validate balanced brackets.
6. Find first non-repeating character.
7. Rotate an array by k.
8. Solve Two Sum with a hash map and explain lookup-before-insert.
9. Traverse a graph with BFS and DFS.
10. Find binary-tree height.
